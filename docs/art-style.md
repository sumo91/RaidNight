# 像素美术风格规范（T17 基准）

本文是 `src/art/` 管线的风格契约：尺寸、调色板、后处理链、识别性精修标准。
样张在 `docs/art/samples/`（`npm run gen:art` 可随时重生成，字节可复现，
`MANIFEST.json` 登记每个资产的 sha256）。

## 三条来源、一条出口（混合产能，DESIGN「美术」）

| 来源 | 入口 | 说明 |
| --- | --- | --- |
| 手绘/精修字符画 | `src/content/portraits.ts`、`src/content/icons.ts` | 高频识别资产（9 职业、徽记），数据驱动、可逐像素编辑 |
| 素材包 | `ingestExternal(grid)`（src/art/pipeline.ts） | 外部 PNG 解码 → RGBA 网格后并入同一条链 |
| AI 补量 | `ingestExternal(grid)` | 同上；AI 稿一律视为需精修的草稿（见授权文档） |

三条来源都必须整链过**统一后处理**（`src/art/post.ts`），没有旁路：

1. **量化**：所有不透明像素收敛到全局调色板最近色（加权 2-4-3 距离）；
2. **描边**：不透明像素的外轮廓（四邻域含透明）统一压成玄墨 `#171226`。

链路幂等（过两遍 = 过一遍），对同一输入严格产出同一字节（测试锚定）。

## 全局调色板（40 色）

定义在 `src/art/palette.ts`。暗色奇幻、与 UI 深紫外壳同底色。
改板 = 改全局风格：只允许增删条目，不要顺手改已有色的 hex。

## 画布尺寸规范

| 资产 | 画布 | 现行内容 |
| --- | --- | --- |
| 职业肖像 | 24×24 | `content/portraits.ts`，9 职业 + 未知占位 |
| 职能图标 | 12×12 | 坦克盾 / 治疗十字 / 输出剑 |
| 徽记 | 16×16 | 告捷金杯 / 失利碎盾 |
| 品质宝石 | 8×8 | 白/绿/蓝/紫 |

统一骨架（9 职业肖像共用）：头部居中 x7–16、眼线 y5–6、肩线 y9、
躯干收于 y20–21 —— 保证九张摆一起是一套。

## 呈现规矩（UI 侧）

- 所有像素图走 `src/ui/artwork.ts` 的 `pixelImg()`，统一挂 `.pixel-art`
  （`image-rendering: pixelated`），全项目唯一出口；
- 缩放只用整数倍：肖像 24（1:1，列表）/ 72（3 倍，详情），徽记 32（2 倍），
  职能图标 24（2 倍）与 12（1:1，阵容行），宝石 16（2 倍）。

## 9 职业识别性精修标准（样张评审基准）

样张：`docs/art/samples/classes.png`（3×3、6 倍放大）。
2026-10 评审：AI 视觉评审平均 4.67/5（最低单张 4/5）。
每张精修稿（手绘替换或 AI 草稿修版）合入前必须同时满足：

1. **保住 identity 要素**：`content/portraits.ts` 每个肖像的 `identity`
   清单（主色 + 标志剪影）逐项在图上可指出；
2. **同骨架**：头部/肩线/躯干落在统一骨架区间内，九张并排不跳；
3. **同色板**：过 `isWithinPalette` 校验（测试在跑）；
4. **过链不变质**：后处理链幂等，精修稿过链后像素不漂移；
5. **缩放可辨**：1:1 尺寸（24×24）下能认出职业 —— 放大图好看不算数。

已知待精修项（下轮手绘优先）：战士阔剑与躯干的分离度、
牧师法杖加宽（现为 1px 木杆 + 2×2 光球）、猎人弓身弧度加大（已从
直线双列改为三层弧，仍可再夸张）。
