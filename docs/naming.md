# 专有名词对照表(开发文档)

依据 [ADR-0002](./adr/0002-ip-adjacent-naming.md):商业发布不能使用暴雪 IP 专有名词。
处理原则 —— ①通用奇幻词(职业名:战士/法师/牧师等)保留;②结构性玩家文化
(DKP、G团、野团、周 CD、40 人团)保留;③全部专有名词(地名、副本名、首领名、
阵营名)一律原创命名,结构上与经典 60 年代一一对应。

**本表只存在于本开发文档,不进游戏**(不出现在界面文案、代码字符串与存档中)。
命名表是所有内容生产的必经关卡:先有对照、后做内容;若未来收到权利方投诉,
按本表批量换名。新增内容时在此登记,内容文件头只留指引不重复表格。
