# WowIdle 设计基准（v1）

本文是设计访谈的共识基准：只记结论与工作值，决策理由见 [ADR](./adr/)，术语定义见 [GLOSSARY](../GLOSSARY.md)。

## 愿景

单机放置模拟：你是魔兽风 MMO 里的公会会长，从 6 人练级小会一路带成服务器传奇公会。买断制、轻操作、深模拟。

## 产品定位

- 平台：Steam（Win 优先、macOS 跟进）+ TapTap（Android）；iOS 暂缓；中文先行。
- 商业：买断（约 ¥22–30），无内购无广告无后端（ADR-0003）。
- 节奏：一轮（建会 → 通关当期最终团本）≈ 6–8 现实天、约 10 小时主动操作；首次可连玩 1 小时以上；日均约 1 小时碎片化操作。
- 对标：《克鲁赛德战记：英雄之城》《巴尔的遗产》的桌面陪伴形态，但离线结算完备、操作更轻、模拟更深。

## 核心体验

三柱：**组建之乐（主柱，ADR-0006）**——招募、划分小队、编成团队；**裁量之乐**——装备分配、资源投向、开荒节奏；**观赛之乐**——团本直播、日志复盘、首杀竞速。

## 世界观与 IP

60 级经典时代结构，擦边致敬命名（ADR-0002）：职业名与玩家文化（DKP、G团、野团、周 CD）保留，全部专有名词原创，对照表只在开发文档中。

## 时间与节奏

- 模拟运行于游戏时间（ADR-0004），工作值 **1 现实天 = 1 游戏周**（单一可调常量；调优方向可以更快）。
- 反馈原则：任何安排后，可感知反馈在现实分钟级到达；装备更新至少每现实天一次。
- 离线：同速率推进、无上限、自动层照常运转；回来收菜读日志。
- 团本 CD = 游戏周 → 现实上每天一个团本夜。

## 核心系统

- **团员**：职业（9）+ 专精、等级、8 部位装备与装等、三维状态（心情/忠诚/疲劳）、出勤画像、性格标签 1–2、技艺评级、轻量关系网（每人 ≤2 条）。
- **编成**：小队（5 人）是全游戏原子；职能结构 + 9 职业小队光环；团队 = 8 小队，另有团队检查（总坦克/治疗、职能覆盖）。5 人本 = 1 小队，战场 = 2–3 小队。
- **活动结算**：统一结算引擎，三级演出——练级静默计数；5 人本/野团/G团结果卡 + 短日志；团本直播视图（首领血条、40 人点阵、滚动日志），赛前决策、赛中观赛。
- **开荒决策面**：团本夜按首领顺序结算，成败由装等、职能、光环决定；赛前可调三件事——消耗品预算（金库拨款买药水合剂）、世界 Buff（花游戏时间与金币的时效增益）、编成微调（职能配比与光环取舍）。团灭代价 = 修理金 + 疲劳 + 士气，无永久损失，下个团本夜再战。
- **内容阶梯**：10–12 张地图（公会平均等级解锁）→ 12–15 个 5 人本（普通/高级/困难/英雄四档）→ 4 档 40 人主力团本 + 2 个 20 人休闲团本（装备追赶、G团主场景）。
- **经济**：双钱包（个人金 / 公会金库）；分配制度三选一可换：DKP / GKP / 会长裁量，各有忠诚、金钱流向的代价收益；自肥累积忠诚与声望代价。
- **招募**：申请池（声望决定数量质量）、世界频道招募帖（花金库）、挖角（仅背景公会，贵、看诚意）；忠诚过低或长期冷板凳自动退会。
- **声望与荣誉**：7 档 × 3 星；荣誉墙 = 首杀徽章、里程碑、稀有陈列、军衔记录、名人堂（含离会团员去向）。
- **竞争公会**：虚拟服务器含上百 NPC 公会，多数为背景公会；少数竞争公会受橡皮筋规则约束（正常推进时玩家首杀稳拿，长期停滞才被超车），另以市场抬价、抢苗子刷存在感；不锁内容、不掠夺体验。
- **PvP**：战场（分梯度）+ 荣誉阶梯（军衔/军装，第二装备来源）；竞技场留给下一时代。
- **会长**：会长角色在名册中可上场可吃装备；管理三层 = 自动层（默认）+ 计划层（每周目标与开团）+ 事件层（仅接口，ADR-0005）。
- **装备**：8 部位、4 品质（白/绿/蓝/紫）、装等驱动；团本 tier 出 5 件套（2/5 件效果）；数据驱动生成物品表。

## UI 形态

- 竖屏优先（一套布局三端派生）：五页签 = 名册（首页）/ 编成 / 日程 / 世界 / 金库·荣誉。
- 横屏 = 双栏（名册 + 详情）。
- 小组件模式：下一场活动倒计时 + 最近结果掉落 + 资源条；hover 展开、点击开全窗；窗口大小位置可调、贴边置顶。

## 美术

像素风；混合产能——职业形象、首领等高频识别资产手绘/精修，地图与图标用素材包 + AI 补量并统一后处理。

## v1 边界（明确不做）

转生/多周目（终局 = 通关最终团本；后续做"下一个时代"扩展）；竞技场；云同步（v2，数据模型预留）；事件内容（接口保留）；iOS；英文。

## 未决项

- 正式游戏名（WowIdle 为工作名）。
- 音频方案。
