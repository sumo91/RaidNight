# 买断制 + 纯单机无后端

决定：买断制（Steam 一次性定价约 ¥22–30，TapTap 同价），无内购、无广告、无账号系统、无服务器；存档为本地文件，支持手动导出/导入，格式自第一版起版本化。理由：内购/排行需要账号与防作弊体系，与纯单机本地存档矛盾；参照品《克鲁赛德战记：英雄之城》以 ¥24 买断验证了品类可行；开发量最小。数据模型按"将来可同步"设计（基于时间戳推进、离线结算幂等），云同步留给 v2。

**Consequences**: 没有长线运营收入模型，长线靠"下一个时代"扩展内容包；Steam/TapTap 成就走平台 API，云存档用 Steam Cloud 即可满足大部分同步需求。
