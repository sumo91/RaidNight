# 模拟运行于加速的游戏时间

决定：整个模拟运行在游戏时间上，现实时间只按一个固定比率常量映射为游戏时间，不设任何现实时间硬门。节奏设计原则（会长原话）："一切以游戏内需要多久给玩家反馈为节奏原则进行设计"。团本周 CD、活动排期、成长速度全部以游戏时间计。

**Considered Options**: 1:1 实时（被否）——与"周 CD × 4 档团本 ≈ 4+ 周"和"一轮约一周/10 小时"的数学直接冲突，且强迫玩家按现实时钟守点，体验冲突会越积越多。

**Consequences**: 桌面小组件是"快进中的直播窗"而非挂机时钟；一切推送、守点、限时促销类设计被排除；游戏时间比率是单一可调常量，供节奏调优。
