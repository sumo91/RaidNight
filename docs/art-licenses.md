本文是本项目全部像素资产的授权台账与引入规范。**任何新资产合入仓库前，
必须先在本文登记**；未登记来源的资产不允许进 `src/content/`、`docs/art/`
或任何随包分发目录。

## 第三方素材包引入规范（未来生效）

1. 只接受授权明确允许**商业发行、免署名或可署名**的素材包
   （例：CC0 / OFL 类比对的像素资源、Kenney 系列等）；
2. 引入时在本表登记：素材包名称 / 作者 / 来源 URL / 许可名称 / 取用
   文件清单 / 引入日期 / 许可证文本存档路径（许可证原文一并入库到
   `docs/art/licenses/`）；
3. 素材必须栅格化为 RGBA 网格后经 `ingestExternal()` 过统一后处理
   （量化 + 描边），不允许直连贴图；
4. 禁止引入授权不明、「仅个人使用」、或要求源码开放的许可
   （本项目是买断制闭源商业发行，ADR-0003）。

## AI 生成资产规范（未来生效）

1. AI 补量只做**草稿**：过 `ingestExternal()` 量化到全局色板后，
   必须人工精修（识别性资产按 `docs/art-style.md` 精修标准走）；
2. 登记生成工具、模型版本、日期与提示词摘要于下表；
3. 生成工具的服务条款必须允许商用产出；有争议的工具产出不得合入；
4. AI 草稿不计入「项目自有原创」——精修定稿（人工逐像素可追溯修改）
   才可按原创登记。

## 程序生成资产的原创性说明

`src/art/` 管线 + `src/content/` 字符画全部为本仓库首次提交的原创代码
与像素数据（git 历史可追溯），不包含任何对既有游戏资产的描摹、
临摹或数据提取。命名与世界观合规另见 ADR-0002。
